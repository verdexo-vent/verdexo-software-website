Questions

Before you book the demo.

Clear answers now make for a better project later.

Is this really a one-time software price?+

Yes. The software licence is purchased once. Infrastructure has an annual cost because hosting, database and server services continue to run after the first year.

What exactly is included in the first year?+

Standard hosting, backend and database infrastructure for the agreed software scope. Domain charges, paid messaging and external services are separate unless written into your quote.

Can the software be changed for my business?+

Business details, services, staff, prices and supported settings can be configured. Larger workflow changes are assessed and quoted as custom work.

Are WhatsApp and SMS free?+

No. The automation can be connected to the software, while message usage is charged by the relevant provider. You only add it if it is useful for your business.

Will it work on phones and tablets?+

The web software is designed to work across modern desktop, tablet and mobile browsers. Some complex administration is naturally easier on a larger screen.
